# App Streamlit — TP Métodos Estadísticos para IA

Archivos: `app.py`, `requirements.txt`, `01_Buenos_Aires_Castelar.csv`

## Correr en tu computadora
```
pip install -r requirements.txt
streamlit run app.py
```

## Publicar (GitHub + Streamlit Community Cloud)
1. Creá un repositorio en GitHub y subí estos 3 archivos (los tres en la raíz del repo).
2. Entrá a https://share.streamlit.io, iniciá sesión con GitHub y elegí "New app".
3. Seleccioná el repositorio, la rama `main` y el archivo `app.py`. Deploy.
